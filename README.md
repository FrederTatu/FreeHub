# FreeHub

FreeHub — учебный веб-проект на Django, представляющий собой платформу для фрилансеров и их проектов.

Пользователи могут просматривать работы, открывать страницы проектов, переходить в профили фрилансеров, регистрироваться, входить в аккаунт и добавлять собственные проекты.

## Основные возможности

- Главная страница с популярными работами
- Каталог проектов
- Каталог фрилансеров
- Публичные профили фрилансеров
- Страница отдельного проекта
- Регистрация пользователей
- Авторизация и выход из аккаунта
- Личный кабинет
- Добавление проектов
- Редактирование профиля
- Привязка проектов к пользователям
- Отображение категорий и тегов проектов
- Адаптивная вёрстка для разных разрешений экрана

## Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/FrederTatu/FreeHub.git
```

### 2. Перейти в папку проекта

```bash
cd FreeHub
```

### 3. Создать виртуальное окружение

Windows:

```bash
python -m venv .venv
```

### 4. Активировать виртуальное окружение

PowerShell:

```bash
.venv\Scripts\Activate.ps1
```

### 5. Установить зависимости

```bash
pip install -r requirements.txt
```

### 6. Запустить сервер

```bash
python manage.py runserver
```

После запуска сайт будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

## Основные страницы

```text
/                       Главная страница
/catalog/               Каталог проектов
/freelancers/           Каталог фрилансеров
/profile/<username>/    Публичный профиль
/project/<id>/          Страница проекта
/add-project/           Добавление проекта
/account/               Личный кабинет
/register/              Регистрация
/login/                 Вход
/logout/                Выход
```

## База данных

В проекте используется SQLite.

В базе данных хранятся:

- пользователи;
- проекты;
- категории;
- информация об авторах проектов.

## Адаптивность

- 1920 px
